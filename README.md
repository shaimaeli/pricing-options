Application web permettant d’évaluer des options européennes à l’aide de plusieurs méthodes de pricing : modèle de Black-Scholes, simulation de Monte Carlo, méthodes numériques d’Euler et de Milstein, ainsi qu’une approche basée sur le Machine Learning.
L’application permet également de récupérer des données de marché et d’analyser la convergence des différentes méthodes numériques
